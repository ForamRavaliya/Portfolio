# Modern Animated Portfolio

A production-ready developer portfolio built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Customize

- Edit personal details, links, projects, skills, education, internships, and resume highlights in `data/portfolio.ts`.
- Replace `public/resume.pdf` with your final resume using the same filename.
- Replace project preview images in `public/projects/`.

## Deploy

Push the project to GitHub, import it in Vercel, and deploy with the default Next.js settings.
